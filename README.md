# Dev Kumar Dahiya: portfolio

Single-page portfolio built with **React, TypeScript, Vite and Tailwind CSS**, with self-hosted fonts (Bricolage Grotesque and IBM Plex).

Live: https://potrfolio-puce.vercel.app

## Edit the content

Everything the site says lives in `src/data.ts`: profile, featured project, project list, experience, research, skills and education. The résumé download is `public/Dev_Kumar_Dahiya_Resume.pdf`.

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
```

Deployed on Vercel from the `main` branch.
